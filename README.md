# Brawl Stars Draft Recommender

An AI-powered draft recommendation system for **Brawl Stars**, combining computer vision and competitive match statistics to support strategic decision-making during competitive drafts.

## Overview

This project aims to identify Brawlers from visual game screenshots and generate strategic draft recommendations based on competitive statistics.

### Key Components

- **Computer Vision:** Visual recognition of Brawlers from game screenshots.
- **Data Analysis:** Exploration and processing of competitive match statistics.
- **Draft Recommendation:** Data-driven suggestions to improve team composition and draft decisions.
